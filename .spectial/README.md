# .spectial

This folder was generated by [Spectial](https://github.com/Flex97115/spectial)
(`spectial:extract` skill). It is the product file of this repository: every
feature of the product, who can use it (`access`), the dependencies between
features, and the code and tests implementing each one.

- `product.yaml` — product manifest (name, stack, conventions, actors, domains)
- `features/*.yaml` — one file per feature
- `graph.json` / `graph.mmd` — feature dependency graph (generated)
- `graph.html` — interactive graph viewer; click a node to read its feature (generated)
- `GRAPH_REPORT.md` — god nodes, leaf features, per-domain counts (generated)
- `regeneration-gaps.md` — Rust/MongoDB porting decisions taken when this
  product base was regenerated from its PostgreSQL original; read it before
  treating a missing capability as a bug
- `exports.yaml` — where this product base has been published (written by `spectial:export`)

To update after code changes, run the `spectial:extract` skill again.
To validate manually, run the `validate.py` bundled with the skill:
`python <skill-folder>/validate.py .spectial/ --repo-root .`
